Java - Введение в объектно-ориентированное программирование

Java - это объектно-ориентированный язык программирования, разработанный компанией Sun Microsystems в 1995 году. Основная концепция Java - "Write Once, Run Anywhere" (WORA), что означает возможность запуска программы на любой платформе без необходимости перекомпиляции.

Виртуальная машина Java (JVM)

Java использует виртуальную машину (JVM) для запуска программ. JVM - это программная оболочка, которая интерпретирует байт-код Java и выполняет его на конкретной платформе. Это обеспечивает платформонезависимость Java приложений.

Классы и объекты

Класс в Java - это шаблон или чертеж для создания объектов. Он определяет поля (переменные) и методы (функции), которые будут доступны объектам этого класса. Объект - это экземпляр класса, конкретное воплощение шаблона в памяти.

Пример объявления класса:
class Person {
    String name;
    int age;

    void displayInfo() {
        System.out.println("Имя: " + name + ", Возраст: " + age);
    }
}

Интерфейсы

Интерфейс в Java - это контракт для классов. Он определяет набор методов, которые класс должен реализовать, но не предоставляет их реализацию. Интерфейсы используются для достижения полиморфизма и множественного наследования поведения.

Пример интерфейса:
interface Drawable {
    void draw();
}

Наследование

Наследование - это механизм, позволяющий одному классу наследовать поля и методы другого класса. Класс, который наследует, называется подклассом (child class), а класс, от которого наследуют - суперклассом (parent class). В Java используется ключевое слово extends для наследования.

Пример наследования:
class Animal {
    void makeSound() {
        System.out.println("Животное издает звук");
    }
}

class Dog extends Animal {
    void makeSound() {
        System.out.println("Гав-гав!");
    }
}

Полиморфизм

Полиморфизм - это способность объекта принимать различные формы. В Java полиморфизм реализуется через наследование и интерфейсы. Он позволяет использовать объекты разных классов через общий интерфейс или суперкласс.

Пример полиморфизма:
Animal myDog = new Dog();
myDog.makeSound(); // Выведет "Гав-гав!"

Инкапсуляция

Инкапсуляция - это принцип сокрытия внутренней реализации объекта от внешнего мира. В Java это достигается через модификаторы доступа: private, protected, public. Инкапсуляция обеспечивает контролируемый доступ к полям класса через геттеры и сеттеры.

Пример инкапсуляции:
class BankAccount {
    private double balance;

    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
}

Абстракция

Абстракция - это процесс выделения существенных характеристик объекта и игнорирования несущественных. В Java абстракция реализуется через абстрактные классы и интерфейсы. Абстрактный класс не может быть инстанцирован напрямую и предназначен для наследования.

Пример абстрактного класса:
abstract class Shape {
    abstract double calculateArea();
}

class Circle extends Shape {
    double radius;

    double calculateArea() {
        return Math.PI * radius * radius;
    }
}

Исключения

Java предоставляет механизм обработки исключений для управления ошибками во время выполнения программы. Исключения - это объекты, представляющие ошибочные ситуации. Блок try-catch используется для перехвата и обработки исключений.

Пример обработки исключений:
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Деление на ноль!");
}

Коллекции

Java Collections Framework предоставляет набор классов и интерфейсов для работы с группами объектов. Основные интерфейсы: List (упорядоченный список), Set (множество уникальных элементов), Map (пары ключ-значение).

Примеры коллекций:
List<String> names = new ArrayList<>();
names.add("Алиса");
names.add("Боб");

Map<String, Integer> ages = new HashMap<>();
ages.put("Алиса", 25);
ages.put("Боб", 30);

Обобщения (Generics)

Обобщения позволяют создавать классы, интерфейсы и методы, которые работают с различными типами данных, обеспечивая при этом типобезопасность на этапе компиляции. Это позволяет избежать явного приведения типов и обнаруживать ошибки на ранней стадии.

Пример обобщенного класса:
class Box<T> {
    private T content;

    void set(T content) {
        this.content = content;
    }

    T get() {
        return content;
    }
}

Потоки (Streams)

Java 8 представила Stream API для функциональной обработки коллекций. Потоки позволяют выполнять операции фильтрации, маппинга и агрегации данных в декларативном стиле.

Пример использования потоков:
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> evenNumbers = numbers.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());

Лямбда-выражения

Лямбда-выражения - это способ представления анонимных функций в Java. Они делают код более кратким и выразительным, особенно при работе с функциональными интерфейсами.

Пример лямбда-выражения:
List<String> names = Arrays.asList("Алиса", "Боб", "Чарли");
names.forEach(name -> System.out.println(name));

Многопоточность

Java предоставляет встроенную поддержку многопоточности через класс Thread и интерфейс Runnable. Многопоточность позволяет выполнять несколько задач одновременно, что улучшает производительность приложений.

Пример создания потока:
Thread thread = new Thread(() -> {
    System.out.println("Поток выполняется");
});
thread.start();

Заключение

Java - мощный и универсальный язык программирования с богатой экосистемой библиотек и фреймворков. Понимание основных концепций ООП, таких как наследование, полиморфизм, инкапсуляция и абстракция, является ключом к эффективному программированию на Java.
